# AI-Powered Chatbot Development for Customer Support Automation

## ITSU2006 - Assessment 3

### Project Overview
This project proposes an AI-powered customer support chatbot
for AussieCart Pty Ltd, a fictional Australian e-commerce retailer.

### Project Objectives
- Automate routine customer enquiries.
- Provide 24/7 customer support.
- Improve response efficiency and customer satisfaction.
- Support escalation to human agents.
- Protect customer information.

### Project Constraints
- Project duration: 22 weeks
- Planned budget: AUD 120,000
